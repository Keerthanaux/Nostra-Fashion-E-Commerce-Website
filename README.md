# Nostra-Fashion-E-Commerce-Website
Nostra is a stylish fashion store website showcasing new arrivals, most wanted products, and collections with an elegant layout. It is designed to be beginner‑friendly, fast, and fully responsive across devices.

This project is ideal for:

Learning front‑end web development

Practicing real‑world website structure

Showcasing portfolio‑ready UI design

🚀 Features

🏠 Home page with hero section & offer banner

🆕 New Arrivals product grid

❤️ Most Wanted section with slider & wishlist icons

🧥 Collections page with sidebar filters

📞 Contact Us page

📱 Fully responsive navigation bar

🎨 Modern UI with Google Fonts & icons

⚡ Smooth hover effects and basic JavaScript interactions

🛠️ Built With

HTML5 – Page structure

CSS3 – Styling, layout, responsiveness

JavaScript (Vanilla JS) – Interactions & sliders

Google Fonts – Typography

Font Awesome – Icons
